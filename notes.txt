Q1. What is NetSuite and how is it different from other ERPs?
A1.ERP is the idea; NetSuite is a cloud implementation of that idea — it doesn’t replace ERP, it is an ERP system 
(but modern, integrated, and on the cloud).

Q2.What are the main modules available in NetSuite?
A2.NetSuite offers modules for Finance, CRM, Inventory, HR, Projects, and E-Commerce — all customizable through SuiteScript, 
SuiteBuilder, and SuiteTalk integration tools.

Q3.Explain the architecture of NetSuite (client, server, database, UI layers).
A3.“NetSuite uses a 4-tier cloud architecture — client (UI & scripts), server (business logic) user Event Script, Oracle database 
(data layer),and integration layer (SuiteTalk & REST APIs) — all powered by Oracle’s SuiteCloud platform.”

Q4.What is a record in NetSuite? What types of records exist?
A4.A record in NetSuite is a data object representing business entities like customers or sales orders. It can be standard, custom, 
transactional, or non-transactional depending on whether it’s built-in, user-defined, or tied to business transactions.record have unique
id and can be modified using record.load() & record.save().

Q5.Difference between Standard Records and Custom Records.
A5.Standard records are built-in NetSuite records for core operations like Customer or Invoice, whereas custom records are user-created 
data structures designed to meet unique business requirements.Standard record can be acessed using record.load() and custom record is accessed
using the custom_log

Q6.What are forms, fields, and sublists in NetSuite?
A6.“Forms define the UI layout, fields store individual data values, and sublists display related records or line items under a main record.”

Q7.What is SuiteBuilder?
A7.SuiteBuilder is no code tool which is used to customize forms,fields and sublists.

Q8.How do roles and permissions work in NetSuite?
A8.NetSuite uses a Role-Based Access Control (RBAC) system to manage security. Each user is assigned one or more roles, and each 
role defines what data and actions that user can access in the system through permissions.
